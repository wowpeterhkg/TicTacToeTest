# Draw handling

Type: grilling
Status: resolved

## Question

May a full board with no line be resolved by a tiebreak rule (e.g. "O wins"), or must every win be three in a line?

## Answer

No tiebreak. The only win condition is three in a line. Rejected: full-board tiebreak (trivially terminates, but hands one side a forced win and is not a real win), scoring by line count (still ties, needs its own tiebreak).
